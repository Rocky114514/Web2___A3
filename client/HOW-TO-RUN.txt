THIS PACKAGE CONTAINS THE PUBLIC WEBSITE
    index.html        Home page (animated torch + upcoming events)
    search.html       Search / filter charity events
    event.html        Event detail + registrations list + weather
    register.html     Event registration page  (new in A3)
    css\styles.css    design system
    js\*.js           page logic


----------------------------------------------------------------
HOW TO RUN
----------------------------------------------------------------
The REST API must be running first - see the api package.
By default it runs at http://localhost:3000.

Then either:

    (a) simply open index.html in a browser, or

    (b) serve this folder and browse to it:
            npx serve -l 5500      ->  http://localhost:5500

Useful pages once it is open:

    index.html
    search.html
    event.html?id=1
    register.html?id=1


----------------------------------------------------------------
IF THE API IS SOMEWHERE ELSE
----------------------------------------------------------------
Edit ONE line in js\config.js:

    const API_BASE = 'http://localhost:3000';


----------------------------------------------------------------
NOTES
----------------------------------------------------------------
* No CSS or JavaScript frameworks and no external assets are used;
  the site is 100% self-contained (system fonts only).
* The only external service is the optional Open-Meteo weather API,
  and it is reached through our own API, never directly from the
  browser.
* The "Staff Admin" link in the footer expects the admin package to
  be extracted as a SIBLING folder named "admin".
* If a page shows "Could not load events", the API is not running.
